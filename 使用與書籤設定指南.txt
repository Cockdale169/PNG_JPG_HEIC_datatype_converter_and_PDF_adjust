⚡ 個人專用極速轉檔與 PDF 編排工作台 ｜ 使用與書籤設定指南
========================================================================

本工具專為您的日常檔案轉換需求打造，特色為：
- 100% 本機瀏覽器運算，零檔案上傳，隱私完全保密且極速。
- 支援 Apple HEIC、PNG、JPG、JPEG、WEBP 互相轉換與品質/尺寸壓縮。
- 支援 PDF 視覺化頁面拖曳編排、插入增頁、單頁刪除、旋轉與新檔匯出。
- 支援 PDF 檔案體積瘦身壓縮（適合 Email 寄信與大小限制）。

------------------------------------------------------------------------
⭐ 如何加入瀏覽器書籤（即點即用）
------------------------------------------------------------------------

您有以下兩種最便捷的使用方式：

【方法一：最推薦！直接以本機網頁加入書籤（免開任何背景程式）】
1. 直接在檔案總管中「雙擊開啟 index.html」。
2. 網頁開啟後，按下鍵盤快捷鍵「Ctrl + D」（Mac 請按 Cmd + D）。
3. 書籤名稱可取為：「⚡ 本機轉檔與 PDF 工具」，然後點擊「完成」。
4. 以後無論何時，只要在瀏覽器點一下該書籤，就能即時秒開使用！

【方法二：透過本機 HTTP 伺服器 (http://localhost:8899)】
1. 雙擊執行「啟動本機轉檔工具.bat」或「背景默默啟動(無黑窗).vbs」。
2. 瀏覽器會自動開啟網址：http://localhost:8899
3. 在該網址按下「Ctrl + D」加入書籤。
4. （進階開機自動啟動）：若希望電腦一開機就自動在後台常駐，
   只需按下鍵盤「Win + R」，輸入「shell:startup」按 Enter，
   將「背景默默啟動(無黑窗).vbs」的「捷徑」丟進去即可！

🛠️ 三大核心功能操作指南
------------------------------------------------------------------------

1. 🖼️ 圖片轉檔與大小調校：
   - 拖曳一張或多張圖片（包含 iPhone 的 .heic 照片、PNG、JPG 等）。
   - 選擇目標格式（JPG / PNG / WEBP）。
   - 調整品質百分比滑桿或選擇解析度上限（如 Full HD 1920px、等比例縮小）。
   - 點擊「⚡ 開始轉檔與壓縮」，完成後可單張下載或「📦 打包下載全部 (ZIP)」。

2. 📑 PDF 視覺化頁面編排、增頁與刪頁：
   - 拖曳主要 PDF 檔案，系統會秒級渲染出每一頁的即時縮圖。
   - 【排列順序】：直接用滑鼠按住縮圖拖曳調整前後順序。
   - 【新增/合併】：點擊「➕ 插入/追加其他 PDF」，選擇要拼進來的 PDF 頁面。
   - 【減少/刪除】：在任意縮圖右下角點擊「🗑️」垃圾桶圖示即可移除該頁。
   - 【旋轉角度】：點擊「🔄」可對單頁順時針旋轉 90 度，或點上方「全部旋轉」。
   - 完成後點擊「💾 匯出新編排 PDF」即可下載重新排列整理好的乾淨 PDF。

3. 🗜️ PDF 檔案體積壓縮（瘦身）：
   - 拖曳檔案過大的 PDF（如掃描檔、大圖合輯）。
   - 選擇壓縮設定（📱 輕量網路版 / 💻 螢幕閱讀版 / 🖨️ 高解析版）。
   - 點擊「⚡ 開始壓縮瘦身」，系統會在進度條跑完後顯示原大小 vs 瘦身後大小，
     並計算出節省比例，隨即可一鍵下載瘦身後的 PDF！
